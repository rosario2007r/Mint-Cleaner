# Mint Cleaner 2.0

**Pulizia semplice, sistema più leggero!**

Mint Cleaner 2.0 è un'applicazione leggera per la pulizia e il monitoraggio del sistema Linux Mint con ambiente desktop XFCE.

Sviluppato da **Rosario Zingone**.

## ✨ Funzioni principali

- **Pulizia normale:** rimozione della cache delle miniature e dei file temporanei sicuri dell'utente.
- **Pulizia approfondita:** pulizia della cache APT, rimozione dei pacchetti non più necessari e pulizia dei vecchi log di sistema.
- **Monitor CPU:** visualizzazione della percentuale di utilizzo del processore.
- **Monitor RAM:** controllo della memoria utilizzata.
- **Monitor SWAP:** visualizzazione della memoria di scambio.
- **Monitor disco:** controllo dello spazio utilizzato sulla partizione principale `/`.
- **Interfaccia bilingue:** Italiano e Inglese.
- **Tema grafico:** modalità chiara e scura.
- **Impostazioni personalizzabili:** configurazione delle preferenze dell'applicazione.

## 💻 Compatibilità

- Linux Mint
- Ambiente desktop XFCE
- Architettura x86_64
